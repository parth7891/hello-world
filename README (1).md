
# # 💰 Personal Expense Tracker

A simple and user-friendly web application for tracking personal income and expenses. The application helps users understand where their money is going by organizing transactions into categories and displaying spending statistics.




## 🛠️ Technologies Used
HTML5
CSS3
JavaScript
Chart.js
LocalStorage

## 🚀 Getting Started
1. Clone the repository
git clone https://github.com/yourusername/expense-tracker.git
2. Open the project
cd expense-tracker
3. Run the application


## 📖 How to Use
Add a Transaction
Enter the transaction name.
Enter the amount.
Select whether it is income or expense.
Select a category.
Click Add Transaction.
View Your Balance

The dashboard automatically calculates:

Balance = Total Income - Total Expenses
Delete a Transaction

Click the delete button next to a transaction to remove it.
